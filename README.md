# 6축 서보 로봇팔 + AI (비전 기반 픽앤플레이스)

로봇 SW 부트캠프에서 만든 **정기구학(FK)·자코비안** 시뮬레이션을 실물 6축 로봇팔로 내리고,
**Jetson Orin Nano**로 물체를 인지해 집는 것을 목표로 하는 프로젝트입니다.
시뮬레이션이 곧 이 팔의 두뇌가 되도록, 부트캠프 코드를 그대로 재사용합니다.

## 구조 (인지 → 계획 → 구동)

```
IMX 카메라(Jetson 내장) ─┐
                        ├─ [Jetson Orin Nano] YOLO 물체탐지 + FK/IK/특이점 계산
서보6~9 + PCA9685 + 5V ─┘         │ 관절각 명령
        프린트 6축 팔  ←──────────┘  (2·3주차 FK/자코비안 재사용)
```

| 층 | 역할 | 재사용 출처 |
|---|---|---|
| 인지(Perception) | 카메라로 물체 탐지 → 목표좌표 | Jetson + YOLO |
| 계획(Planning) | 목표좌표 → 관절각 (IK) + 특이점 회피 | 부트캠프 2·3주차 |
| 구동(Actuation) | 관절각 → 서보 구동 | PCA9685 + 서보 |

## 파일

| 파일 | 내용 |
|---|---|
| [`arm.py`](arm.py) | 기구학 — FK(정기구학)·수치 자코비안·감쇠최소자승 IK. 자가검증 포함 |
| [`m0_servo.py`](m0_servo.py) | M0 — PCA9685 서보 구동 + 서보별 트림 캘리브레이션. 매핑 로직 자가검증 |

```bash
python arm.py        # 기구학 자가검증 (IK 왕복 + 자코비안 일치)
python m0_servo.py   # 서보 매핑 로직 검증 (하드웨어 없이 동작)
```

## 마일스톤

- [x] 기구학 이식 (`arm.py`) — FK/IK/자코비안, 자가검증 통과
- [x] M0 서보 구동 골격 (`m0_servo.py`) — 트림 캘리브레이션 구조, 매핑 검증
- [x] 부품 주문
- [~] STL 출력 (진행 중 — 그리퍼 배치 출력, 조인트·베이스 남음. [PRINTING.md](PRINTING.md) 참고)
- [ ] 조립 → 링크 실측(`LINKS`)·서보 트림(`ServoCal`) 보정
- [ ] M0 실행 — 서보 1개 왕복 (배선·전원·라이브러리 검증)
- [ ] M1 — 자코비안 IK로 지정 좌표 도달
- [ ] M3 — IMX 카메라 + YOLO → 목표좌표 → 집기 (루프 완성)

## 하드웨어 (BOM)

- 팔 설계: [6 DOF Robotic Arm (MG996R / MG90S)](https://www.thingiverse.com/thing:6152986) (CC BY, 3D 프린트)
- 서보: MG996R ×5(큰 관절) + MG90S ×4(손목·그리퍼)
- 드라이버: PCA9685 (16채널 PWM, I2C)
- 전원: 5V 6A 아답터 + DC잭 단자대 + 1000µF 커패시터 (⚠️서보 전원은 Jetson과 분리)
- 기구: M2 볼트/너트/와셔, 6000-2RS 베어링 ×2, 3mm 카본로드
- 제어: Jetson Orin Nano (+ 내장 IMX 카메라)

## 배선

```
Jetson I2C(SDA/SCL) → PCA9685 SDA/SCL, VCC(로직), 공통 GND
5V 6A 아답터 → DC잭 단자대 → PCA9685 V+/GND (서보 전원)
1000µF 커패시터 → V+/GND 병렬 (피크 완충, 극성 주의)
서보 → PCA9685 3핀 채널에 직접
```

## 캘리브레이션 원칙

하드웨어는 도면대로 나오지 않으므로, 조립 후 **실측값**을 코드에 반영합니다.
- `arm.py`의 `LINKS` — 링크 길이는 조립 후 자로 재서 갱신
- `m0_servo.py`의 `ServoCal` — 서보별 트림/펄스범위/반전을 한 개씩 보정
